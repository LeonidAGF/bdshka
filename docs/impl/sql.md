# Реализация SQL части базы данных

## Оглавление

Для работы базы данных с SQL были реализованы следующие группы классов:
1. Движок и сессия (SqlEngine, EngineSession)
2. Парсер  мапперы (SqlParserImpl, TypeMapperImpl, ExpressionToJavaValueMapper, ColumnValueConverter)
3. Исполнители (CreateTableExecutor, DropTableExecutor, InsertExecutor, SelectExecutor, ..)

## Движок и сессия

Все начинается с движка. Его единственная задача открыть сессию и вернуть EngineSession.
Архитектурно его наличие удобно, потому что оно дает переииспользовать парсер, исполнители.

Сессия уже сложнее. Используя исполнители и парсер из движка он может исполнять какие-то запросы, быть закрыта.
Внутри сессии сначала парсер разбирает запрос на определнные выражения (statements).
Затем для каждого выражения подбирается первый исполнитель, который может его исполнить, и исполнение передается ему.

## Парсер и мапперы

Парсер работает очень просто. Он является обёрткой-адаптером над [JSqlParser](https://github.com/JSQLParser/JSqlParser/tree/master).

TypeMapper согласно документации PostgreSQL преобразует разные алиасы одного типа в целевой. Например: CHARACTER и CHAR

ExpressionToJavaValueMapper преобразует экземпляр класса выражения к экземпляру встроенного класса Java или примитиву. Он используется для отделения слоя парсинга.

ColumnValueConventer по типу колонки преобразует объект к нужному типу.

Мапперы используются далее в исполнителях.

## Исполнители

Каждый исполнитель (StatementExecutor) умеет исполнять свой вид выражения (Expression). Были реализованы исполнители для создания таблиц, вставки данных, удаления таблица, выбора данных.

Для взаимодействия с разными экзекуторами унифицированно есть отдельный интерфейс StatementExecutor.

Каждый исполнитель валидирует выражение перед исполнением, так как оно может быть более продвинутое, чем может распарсить парсер, и не поддерживаться для исполнения.

Исполнители в своей реализации используют методы storage для взаимодействия с базой данных, исполняют задуманные операции. Используются findTable, createTable, dropTable, методы таблицы для получения данных, например, scan.

В качестве возвращаемого значения используется QueryResults.
