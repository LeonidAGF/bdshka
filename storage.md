# Работа по storage

# Schema
SchemaImpl хранит список колонок, ищет колонку по имени без учёта регистра, проверяет пустые имена и дубли. В Column добавил геттеры, потому что без них схема не могла читать описание колонок.

# Record
RecordImpl это строка таблицы. Значения лежат в массиве, есть доступ по индексу и по имени колонки. Добавил проверку количества значений и копирование массива, чтобы данные нельзя было поменять снаружи.

# Cursor
Постраничное чтение: TableCursor идёт по страницам и декодирует по одной строке, а SingleRecordCursor отдаёт ноль или одну строку для поиска по ключу. Так таблица не загружается в память целиком.

# Table
TableImpl и Page. Страница фиксированного размера, строки пишутся с конца, каталог слотов с начала. Есть вставка, поиск по PK, обновление, удаление и сканирование. Для поиска использую существующий BTree, добавил ему итераторы по ключам и значениям. Key поддерживает составной первичный ключ, RowId хранит номер страницы и слота. RecordCodec проверяет значения и сериализует их по типу колонки.

# Storage
MemoryStorage: создание, получение, поиск и удаление таблиц. Таблицы хранятся в ConcurrentHashMap.

# Изменения под правки интерфейсов
Подогнал реализации под измененные интерфейсы:
- RecordImpl - добавил schema(), size(), toArray();
- SchemaImpl - getPrimaryKeyIndexes() теперь часть интерфейса;
- TableImpl - добавил name(), scan() теперь возвращает RowCursor;
- TableCursor - отдаёт RowCursor.Entry, то есть RowId и Record;
- MemoryStorage - новый API: createTable(name, schema), getTable, findTable, tableNames, dropTable(name, ifExists).

Также обновил тесты под новые интерфейсы: вставку, поиск, сканирование, обновление, удаление, составной ключ, ограничения схемы и работу MemoryStorage.
